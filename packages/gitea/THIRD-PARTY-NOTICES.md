# Third-party notices

`wiredown-renderer.js` and the files under `chunks/` bundle other people's
code, and `fonts/` holds fonts. Licence banners that the bundled sources
carry are kept at the end of each file.

| Component                                            | Version | Licence      | Copyright                           |
| ---------------------------------------------------- | ------- | ------------ | ----------------------------------- |
| `@excalidraw/excalidraw` and the packages it bundles | 0.18.1  | MIT          | Excalidraw                          |
| `react`, `react-dom`, `scheduler`                    | 18.3.1  | MIT          | Meta Platforms, Inc. and affiliates |
| Excalifont (`fonts/Excalifont/`)                     | 1.000   | OFL 1.1 (\*) | Excalidraw                          |

React's licence text is in `licenses/`. Excalidraw's npm package ships no
licence file; its MIT licence is in its source repository.

(\*) Excalifont is copyright Excalidraw ("Copyright (c) 2024 by Excalidraw.
All rights reserved." in the font file) and is published by Excalidraw
under the SIL Open Font License 1.1. The font file itself carries only that
copyright notice, not a licence. The OFL 1.1 text is in
`fonts/Excalifont/OFL.txt`, copied verbatim from the licence record of the
Virgil font in the same Excalidraw package.

This list covers the direct dependencies. Excalidraw bundles further
packages of its own; review them before distributing this bundle publicly.
